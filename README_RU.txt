MAGAZIN Android — проект переноса генератора торговцев One Piece на Kivy.

ОНЛАЙН-СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS (Windows 10, без установки Linux):
1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Создай новый репозиторий, например MAGAZIN-Android.
3. Загрузи в репозиторий ВСЁ содержимое этого архива, включая скрытую папку .github.
4. Открой в репозитории вкладку Actions.
5. Выбери workflow «Build MAGAZIN Android APK» и нажми Run workflow.
6. Дождись завершения сборки со статусом зелёной галочки.
7. Открой завершённый запуск workflow и скачай артефакт MAGAZIN-Android-APK.
8. Распакуй скачанный ZIP — внутри будет APK. Перенеси APK на телефон и установи.

При первом запуске облачная сборка может занять продолжительное время: Buildozer скачивает Android SDK/NDK и собирает зависимости.

ЛОКАЛЬНАЯ СБОРКА (Ubuntu/Linux):
В каталоге проекта выполнить:
  python3 -m pip install --user buildozer cython==0.29.36
  buildozer android debug
APK появится в каталоге bin/.

Данные приложения хранятся в приватной папке приложения на Android:
- База_товаров.xlsx (копируется из assets при первом запуске)
- торговцы.json (библиотека)

В проекте реализованы генерация, редактирование капитала и товаров торговца, добавление вручную и выбор нескольких товаров из базы, поиск/сортировка базы, редактирование базы Excel и библиотека торговцев.

Ограничения первой мобильной сборки: пока не перенесены редактор изображений/карточек библиотеки, импорт/экспорт .merchant и PDF-экспорт; это отдельные следующие этапы. Наличие workflow подготавливает облачную сборку, но не означает, что APK уже собран или проверен на устройстве.
