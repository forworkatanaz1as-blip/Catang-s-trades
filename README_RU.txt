MAGAZIN Android — мобильный генератор торговцев One Piece на Capacitor.

СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS:
1. Загрузите проект в репозиторий GitHub, включая папку .github.
2. В настройках репозитория убедитесь, что GitHub Actions разрешён.
3. Откройте Actions → Build MAGAZIN Android APK → Run workflow.
   Сборка также запускается при каждом push в ветку main.
4. После успешного выполнения скачайте MAGAZIN-Android-debug.apk во вкладке Releases.

Каждый запуск создаёт отдельный релиз с тегом build-<номер запуска>-<попытка>.
Workflow нужны права contents: write для создания релиза и тега.
APK подписан отладочным ключом, создаваемым в среде сборки. Ключи разных
запусков могут отличаться: для установки новой версии может потребоваться
удалить старую, при этом её локальные данные будут удалены. Для стабильных
обновлений и публикации в магазине потребуется собственный ключ подписи.

ЛОКАЛЬНАЯ ПОДГОТОВКА (Node.js 22, Java 21 и Android SDK):
  npm ci
  npm run build
  npx cap add android
  npx cap sync android
  cd android
  ./gradlew assembleDebug

Android-проект генерируется заново в Actions и не хранится в репозитории.
Если он уже создан локально, повторно выполнять cap add android не нужно.
Приложение использует index.html и хранит изменённую базу и
библиотеку в локальном хранилище WebView. Доступны импорт и экспорт JSON.
